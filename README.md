# Jules Operator archive

Jules has been deprecated. This private archive preserves the legacy operator
source for reference; it is not maintained or intended for live operation.

The source includes the former Go API/MCP service, local credential helpers,
batch and scheduler implementation, and their tests. The prompt examples are
separate static material and refer only to RamShared.

The curated examples are in
[`examples/ramshared-prompts.json`](examples/ramshared-prompts.json). They are
historical task examples, not current RamShared requirements.

Historical operator documents, evidence reports, and old task manifests are
excluded. No live credentials or operational state are included.
